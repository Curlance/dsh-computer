# README visual assets

- `logo.svg`: original desktop-and-cursor mark.
- `overview.svg`: desktop workflow illustration (1120 × 510).

These are editable, self-contained SVGs without scripts, external fonts or raster dependencies. The interface is a schematic, not a product screenshot. Keep that distinction in the README caption.

Editorial references: [ppt-agent](https://github.com/Curlance/ppt-agent), [simulink-formula-modeler](https://github.com/Curlance/simulink-formula-modeler), [Cua](https://github.com/trycua/cua), and [Browser Use](https://github.com/browser-use/browser-use).
